# About references to files that are not here

This repository keeps only the parts of [caduceus-ep7](https://github.com/cakelesscoder/caduceus-ep7) that the firmware
built here uses. Several documents (`FIRMWARE_GUIDE.md`, `CODE_SPACE_MAP.md`, `BUTTONS.md`, ...) come from that project and
cite its other documents, patches and tools (film looks, aspect ratio, grain, Control Panel, SD bundles, ...). Those files
are not carried here: look them up in the upstream repository. The address maps in `CODE_SPACE_MAP.md` still list the code
space used by those upstream features, which is useful if you want to add a patch without overlapping one of them.
